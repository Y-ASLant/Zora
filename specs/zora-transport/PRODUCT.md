# Zora Transport 文件传输系统

## Summary

移除半成品 `zap_sftp`，以 `zora_transport` 提供稳定的远程文件系统和文件传输能力，并完整接入现有 WarpUI SFTP 面板。用户应能够像使用成熟远程文件管理器一样浏览、操作、上传和下载远程文件，同时看到可靠、可控制的传输状态。

## Problem

当前文件浏览器把协议操作、后台任务和 UI 状态耦合在一起。上传/下载只能在视图内部维护，进度不会持续刷新，任务缺少暂停、恢复、重试和目录级汇总，协议层也无法复用于其它远程文件功能。

## Goals / Non-goals

### Goals

- 用 `zora_transport` 完全替换 `zap_sftp`，不保留旧 crate 的生产调用方。
- 为 SSH 远程文件操作提供统一接口，覆盖 SFTP、文件元数据、目录递归和安全路径处理。
- 提供独立于 UI 的传输任务生命周期：排队、运行、暂停、恢复、取消、失败、重试和完成。
- 让现有 SFTP 面板完整使用新核心，并提供实时进度、任务控制、目录传输、拖放上传和冲突处理。

### Non-goals

- 本次不把 NyaTerm 的 Tauri/React 前端移植到 WarpUI。
- 本次不新增 AI 助手、WebDAV/S3 云同步、串口/Telnet 会话等与文件传输无直接关系的产品线。

## Figma

Figma: none provided。沿用现有 WarpUI 主题和组件，仅补齐传输状态与操作入口。

## Behavior

1. 打开 SFTP 面板后，应用在后台建立 SSH 连接并读取远程 home 目录；连接中显示加载状态，认证失败、超时、权限错误和远程路径错误显示可读错误，不阻塞 UI。

2. 连接成功后，文件列表按目录优先、名称不区分大小写排序；显示名称、类型、大小、修改时间和权限。空目录、加载中、过滤无结果和连接失败都有独立的可理解状态。

3. 用户可以通过面包屑、根目录、返回、前进、上级和刷新导航。导航历史只在路径真正改变时追加，刷新不会破坏当前路径或传输任务。

4. 用户可以搜索当前目录名称；搜索只影响显示，不会删除或修改远程条目。清空搜索后恢复完整列表。

5. 用户可以打开目录、查看文件详情、重命名、移动、创建目录、删除文件或递归删除目录。删除、覆盖和关闭活跃传输前必须确认；非法名称和路径遍历输入必须被拒绝。

6. 用户可以通过工具栏、文件选择器或拖放上传一个或多个文件及目录。目录上传保留相对目录结构，远程父目录不存在时按需创建。

7. 用户可以下载文件或目录到本地路径。下载目录保留远程目录结构；目标父目录不存在时自动创建。打开远程文件默认进入下载流程，不覆盖用户已有文件而不提示。

8. 上传和下载先写入临时目标，成功后再替换最终目标；取消或失败不会留下看似完整的目标文件。无法清理临时文件时，错误信息必须包含临时文件位置。

9. 每一个文件或目录传输显示独立任务。任务至少显示方向、名称、当前状态、已传输字节、总字节和进度；目录任务同时显示已完成文件数和总文件数。

10. 活跃任务支持暂停、恢复和取消。暂停后任务不再继续读写，恢复后从当前传输位置继续；取消后任务进入已取消状态并清理临时文件。任务结束后 UI 不得把已完成任务误显示为活跃。

11. 失败任务显示错误原因并提供重试；重试复用原始源路径和目标路径，清理旧任务后重新进入传输队列，不跳过用户确认的覆盖策略。

12. 多个任务可以排队运行，单个任务的状态变化不会影响其它任务。关闭面板只隐藏面板；若仍有活跃任务必须先确认是否取消全部任务。关闭 SFTP pane 时所有任务都被取消并释放连接。

13. 远程文件系统操作通过统一传输接口完成，UI 不依赖具体协议实现。当前迁移以 SFTP 为首选且唯一生产后端；不支持 SFTP 子系统时返回明确错误，后续可在同一接口上增加 SSH/SCP 兼容后端。

14. Windows、macOS 和 Linux 的本地路径可以作为上传/下载目标；远程路径始终使用 `/` 分隔符，Windows 本地反斜杠不能泄漏到远程路径。

15. 文件名包含空格、Unicode 字符和非 ASCII 字符时不得被静默改名或截断。服务器返回的 `.`、`..` 或带路径分隔符的目录条目不得被递归下载到本地目标之外。

16. UI 所有按钮使用现有 WarpUI 主题和外观颜色；按钮状态、错误、暂停、取消和危险操作在深色/浅色主题下都保持可读，并保留键盘导航、Escape 关闭对话框、Backspace 返回上级和 Delete 删除选中项。
